# Registros de decisión de arquitectura

Los ADR viven en Confluence, que es la fuente oficial. Esta carpeta guarda una copia
en el repositorio para que una decisión quede asociada al commit que la implementa,
que es lo que pide la trazabilidad ASR → decisión → implementación → medición.

| ADR | Decisión | Estado |
| --- | --- | --- |
| ADR-1 | Separación de capas con puertos y adaptadores | Propuesta |
| ADR-2 | Comunicación entre módulos no críticos por eventos internos | Propuesta |
| ADR-3 | Modelo de disponibilidad sin superposición y consultable | Propuesta |
| ADR-4 | Flujo de reserva y pago | Propuesta |
| ADR-5 | Autorización por rol | Propuesta |

Al cerrar un ADR, copien aquí la versión final como `adr-00X-<nombre>.md` y
actualicen el estado en Confluence en el mismo pull request.
